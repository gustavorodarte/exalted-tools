
# Exalted Tools
This project is a collection of tools designed to assist players of the tabletop game Exalted. It currently consists of two main projects: Discord Random Roller and Notion Character Sheet.

## Discord Random Roller
The Discord Random Roller is a bot that allows players to roll dice and generate random numbers within their Discord server. The bot is built using Node.js and utilizes the Discord.js library for interacting with the Discord API. It also integrates with the random.org API to ensure truly random results.

## Notion Character Sheet
The Notion Character Sheet is a template designed for organizing and managing character information in the popular productivity tool, Notion. It provides a structured format for tracking character stats, abilities, and other relevant details. The template is created using Markdown and can be easily customized to suit individual preferences.
